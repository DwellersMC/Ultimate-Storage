# Ultimate-Storage

适用于 Minecraft 26.2 的 Fabric 纯服务端共享存储模组。

## 使用

1. 放置配置中的基座方块（默认磁石），并在其上放置木桶。
2. 站在木桶上执行 `/ults create <名字>` 创建输入口。
3. 使用漏斗等物流向木桶输入物品；物品会进入绑定当前存档的共享存储。指向输入木桶且未被红石锁定的漏斗会被逐 Tick 清空并重置传输冷却。
4. 所有玩家可执行 `/ults` 打开只取不存的分类存储界面。

存储界面使用运行时创造模式标签，因此会发现原版及模组添加的分类。左侧分类、分类页和物品页会按玩家保存在当前存档中。物品数量变化时，列表和取出界面会实时刷新。

左键点击物品可打开铁砧数量界面：

- Item 模式按输入数量取出散装物品。
- 整盒模式按输入的潜影盒数量取出，每盒包含 27 组所选物品，并同时消耗对应数量的空潜影盒。
- 物品、空潜影盒或背包空间不足时无法确认；最终确认会重新校验并原子扣除。

管理命令：`/ults create <名字>`、`/ults delete <名字>`、`/ults list [页码]`、`/ults reload`。

配置文件位于 `config/ults/ults.json`。客户端无需安装本模组；可选的 Mod Menu/Cloth Config 界面只编辑本地配置。
